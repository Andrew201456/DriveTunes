# DriveTunes Offline Music

**Ένας απλός, ιδιωτικός music player για iPhone και Android.** Η βασική λειτουργία δεν απαιτεί backend, λογαριασμό, συγχρονισμό με cloud ή ανέβασμα τραγουδιών. Η προαιρετική αντιστοίχιση Spotify playlists απαιτεί εξουσιοδότηση Spotify μόνο για ανάγνωση metadata. Τα αρχεία μουσικής αποθηκεύονται ως Blob σε **IndexedDB** της συσκευής, και το interface λειτουργεί χωρίς internet μέσω Service Worker.

## Πώς το χρησιμοποιείς στο iPhone

1. Ανέβασε το project σε HTTPS hosting με τα αρχεία στην ίδια δομή (GitHub Pages, Cloudflare Pages κ.λπ.). Δεν αρκεί να ανοίξεις το HTML απευθείας από τα Αρχεία ή μέσω `file://`.
2. Άνοιξε το δημόσιο HTTPS URL στο **Safari**.
3. Πάτησε **Κοινοποίηση → Προσθήκη στην Αρχική οθόνη → Προσθήκη**. Επίλεξε «Άνοιγμα ως εφαρμογή» αν εμφανίζεται.
4. Άνοιξε **το εικονίδιο DriveTunes από την αρχική οθόνη** και **τότε** πάτα **«Προσθήκη τραγουδιών»**.
5. Διάλεξε MP3, M4A/AAC, WAV ή άλλο υποστηριζόμενο αρχείο από την εφαρμογή **Αρχεία**. Μπορείς να επιλέξεις πολλά.
6. Όταν τελειώσει η εισαγωγή, βάλε **Λειτουργία πτήσης** και δοκίμασε την αναπαραγωγή. Τα εισαγμένα τραγούδια βρίσκονται τοπικά.
7. Για το αυτοκίνητο, σύνδεσε το iPhone στο Bluetooth του αυτοκινήτου μέσω **Ρυθμίσεις → Bluetooth**. Το DriveTunes χρησιμοποιεί την κανονική έξοδο ήχου του iPhone· δεν κάνει ξεχωριστό pairing.

**Πολύ σημαντικό:** Στο iPhone η εφαρμογή που ανοίγει από την αρχική οθόνη και η καρτέλα Safari μπορεί να χρησιμοποιούν **ξεχωριστή αποθήκευση**. Γι' αυτό: *πρώτα εγκατάσταση, μετά εισαγωγή μουσικής μέσα από το εικονίδιο*.

## Λειτουργίες

- Εισαγωγή πολλών αρχείων με το native file picker (και drag & drop σε υπολογιστή).
- Πραγματική αποθήκευση ήχου ως Blob σε IndexedDB (χωρίς ανεβάσματα σε server).
- Αναπαραγωγή, παύση, seek, προηγούμενο, επόμενο, shuffle, repeat all/repeat one.
- Αγαπημένα, αναζήτηση, ταξινόμηση, μετονομασία τίτλου/καλλιτέχνη, διαγραφή από εφαρμογή.
- Αναγνώριση βασικών ID3 τίτλου/καλλιτέχνη/album από MP3, ή ανάγνωση `Artist - Title.mp3` από το όνομα αρχείου.
- Προφόρτωση **μόνο** του επόμενου τραγουδιού, για πιο άμεση μετάβαση (χωρίς διατήρηση ολόκληρης της συλλογής στη μνήμη).
- Media Session API για χειριστήρια οθόνης κλειδώματος / Bluetooth **όπου το επιτρέπει η έκδοση iOS και ο browser**.
- PWA icon, manifest, service worker για offline interface, αίτημα `navigator.storage.persist()` όπου υποστηρίζεται.

## Περιορισμοί iPhone / Safari — διάβασε πριν βασιστείς στο player

- Το iOS **δεν εγγυάται** μόνιμη αποθήκευση των IndexedDB αρχείων. Αν εκκαθαριστούν δεδομένα εφαρμογής/browser, αφαιρεθεί το web app ή δεν υπάρχει χώρος, ενδέχεται να χαθεί η offline βιβλιοθήκη. **Κράτησε πάντα τα πρωτότυπα αρχεία στην εφαρμογή Αρχεία / σε αντίγραφο ασφαλείας.**
- Η συνέχιση της αναπαραγωγής με **κλειδωμένη οθόνη**, το αυτόματο πέρασμα στο επόμενο τραγούδι και τα Bluetooth πλήκτρα μπορεί να μη λειτουργούν πάντα στο Safari/PWA. Υπάρχουν γνωστοί περιορισμοί του WebKit. Μην θεωρείς ένα web app ισοδύναμο με native iOS audio app.
- Τα υποστηριζόμενα codecs εξαρτώνται από το iOS/Safari. MP3 και M4A/AAC είναι συνήθως οι ασφαλέστερες επιλογές. Δεν υπάρχει μετατροπή αρχείων.
- Η offline μουσική **δεν συγχρονίζεται** μεταξύ συσκευών ούτε αποθηκεύεται στο GitHub. Τα νέα τραγούδια εισάγονται ξεχωριστά σε κάθε συσκευή / web app.
- Η πρώτη εγκατάσταση και η λήψη της εφαρμογής απαιτούν πρόσβαση σε internet. Μετά την πρώτη επιτυχημένη φόρτωση, η εφαρμογή μπορεί να ανοίξει offline.
- Ρύθμισε την αναπαραγωγή **πριν ξεκινήσεις να οδηγείς**, και χρησιμοποίησε τα χειριστήρια του αυτοκινήτου μόνο αν λειτουργούν αξιόπιστα.

## Δημοσίευση

**GitHub Pages:** Δημιούργησε ένα δημόσιο repository, ανέβασε τα παραπάνω αρχεία στη ρίζα και ενεργοποίησε **Settings → Pages → Deploy from a branch → main → /(root)**. Περίμενε να εμφανιστεί το `https://<username>.github.io/<repo>/` URL. Ο player χρησιμοποιεί relative paths ώστε να λειτουργεί και κάτω από repository path.

**Cloudflare Pages:** Δημιούργησε νέο Pages project από το repository. Για στατικά αρχεία χωρίς build, επίλεξε τη ρίζα του repository ως output directory (ή το deployment mode που επιτρέπει απευθείας στατικό upload). Μη δίνεις στα τραγούδια public URL: τα αρχεία θα αποθηκεύονται αποκλειστικά στον browser.

**Τοπικός έλεγχος:**

```bash
python3 -m http.server 8080
```

Άνοιξε `http://localhost:8080`. Οι Service Workers απαιτούν HTTPS ή localhost.

## Ασφάλεια / ιδιωτικότητα

- Δεν υπάρχει API για μουσική, streaming, tracking ή analytics.
- Τα audio Blob δεν μεταφορτώνονται: μόνο τοπική πρόσβαση μέσω browser storage.
- Τα αντικείμενα URL ανακαλούνται όταν αλλάζει ή διαγράφεται τραγούδι.
- Το Service Worker cache περιέχει **μόνο** τον κώδικα, τα εικονίδια και το UI — όχι τα προσωπικά μουσικά αρχεία.

## Spotify links — αντιστοίχιση με offline τραγούδια

Η μπάρα Spotify link δέχεται URLs τραγουδιών και playlists. Εμφανίζει Spotify metadata και αντιστοιχίζει τίτλους/καλλιτέχνες με MP3/M4A κ.λπ. που έχεις ήδη προσθέσει στην τοπική IndexedDB. Τα ταιριασμένα τραγούδια παίζουν offline. **Κανένα αρχείο ήχου δεν κατεβαίνει από Spotify.**

### Μεμονωμένο τραγούδι

Επικόλλησε πλήρες open.spotify.com/track/ link και πάτησε Εύρεση. Χρησιμοποιείται το επίσημο Spotify oEmbed (χωρίς login).

### Ολόκληρη playlist (δική σου ή συνεργατική)

Για τίτλους playlist χρειάζεται Spotify Developer Client ID και Spotify authorization. Από το 2026, το Development Mode απαιτεί Spotify Premium στον δημιουργό εφαρμογής, ενώ το API επιτρέπει ανάγνωση περιεχομένων μόνο σε δικές σου ή συνεργατικές playlists.

1. Δημιούργησε Spotify Developer App και πάρε Client ID (όχι Client Secret).
2. Καταχώρισε στις ρυθμίσεις του Spotify app ακριβώς το Redirect URL που εμφανίζει το DriveTunes.
3. Στο DriveTunes άνοιξε «Σύνδεση Spotify για δικές σου playlists», συμπλήρωσε Client ID και πάτησε «Σύνδεση Spotify».
4. Επικόλλησε ένα open.spotify.com/playlist/ link. Θα εμφανιστούν μέχρι 500 τίτλοι, και θα μπορείς να ακούσεις μόνο όσα υπάρχουν ήδη ως αρχεία στη συσκευή.

Χρησιμοποιείται OAuth PKCE, χωρίς Client Secret στον browser. Τα access tokens κρατιούνται προσωρινά στο sessionStorage και τα metadata μόνο στη μνήμη της σελίδας. Σε iPhone PWA η ανακατεύθυνση Spotify μπορεί να ανοίξει Safari, οπότε ίσως χρειαστεί η σύνδεση από το Safari.

Το offline playback δεν αλλάζει. Η ανάλυση Spotify link απαιτεί internet, αλλά τα δικά σου αποθηκευμένα τραγούδια όχι. Μη σβήνεις τα πρωτότυπα αρχεία.

Επίσημη τεκμηρίωση: https://developer.spotify.com/documentation/embeds/reference/oembed, https://developer.spotify.com/documentation/web-api/tutorials/code-pkce-flow, https://developer.spotify.com/documentation/web-api/reference/get-playlists-items, https://developer.spotify.com/policy

## Ασύρματη μεταφορά τραγουδιών από Windows PC με τοπική IP

Η web εφαρμογή DriveTunes στο iPhone **δεν μπορεί να ανοίξει μόνη της HTTP server στην IP του κινητού**. Γι' αυτό η λύση δίνει μια **τοπική IP στον υπολογιστή** (`http://127.0.0.1:8765/`) όπου εμφανίζεται το drag-and-drop UI, και μεταφέρει τα μουσικά αρχεία απευθείας στην εγκατεστημένη εφαρμογή iPhone με WebRTC.

### Windows (ένα αρχείο, χωρίς εγκατάσταση Python ή Node)

1. Κατέβασε από το repository το **`DriveTunes-PC.cmd`** και αποθήκευσέ το στον υπολογιστή.
2. Άνοιξέ το με **διπλό κλικ**. Χρησιμοποιεί το ήδη ενσωματωμένο Windows PowerShell, κατεβάζει τα **στατικά αρχεία UI** από το δικό σου GitHub repository και εκκινεί έναν μικρό HTTP server δεσμευμένο **μόνο** στο `127.0.0.1`. Δεν χρειάζεται να ανοίξεις ports στο router ή στο Windows Firewall.
3. Ο browser ανοίγει αυτόματα στη διεύθυνση **`http://127.0.0.1:8765/`**. Μπορείς να τη γράψεις και χειροκίνητα στο PC.
4. Στο **εγκατεστημένο DriveTunes του iPhone**, πάτα **Από PC**. Την **πρώτη φορά** συμπλήρωσε τη δημόσια HTTPS διεύθυνση της υπάρχουσας εγκατάστασης **DataTransfer** και πάτα «Έναρξη μεταφοράς». Τις επόμενες φορές η εφαρμογή τη θυμάται και θα αρχίζει μόνη της τη σύνδεση.
5. Στο PC βάλε τον **10-χαρακτήρων κωδικό** που εμφανίζει το iPhone (ή χρησιμοποίησε τον πλήρη σύνδεσμο που αντιγράφεται από την εφαρμογή), πάτα «Σύνδεση» και **σύρε τραγούδια** ή επίλεξε πολλά αρχεία μαζί.
6. Το iPhone αποθηκεύει κάθε αρχείο στην **ίδια IndexedDB** της εγκατεστημένης εφαρμογής και το προσθέτει αυτόματα στη βιβλιοθήκη. Κράτησε ανοιχτά και το DriveTunes στο iPhone και το παράθυρο PowerShell στο PC μέχρι να ολοκληρωθεί η μεταφορά.

Ο local server **δεν δέχεται uploads ούτε διαβάζει τα δικά σου τραγούδια**: σερβίρει μόνο την HTML/CSS/JS σελίδα στον browser του ίδιου υπολογιστή. Τα επιλεγμένα αρχεία περνούν απευθείας από τον browser του PC στο DriveTunes του iPhone με κρυπτογραφημένο WebRTC DataChannel. Ο Cloudflare Worker του DataTransfer μεταφέρει μόνο τα **μηνύματα σύνδεσης**, όχι τα αρχεία. Διαθέτει STUN αλλά **όχι TURN**, άρα κάποια δίκτυα με απομόνωση συσκευών ή περιοριστικό NAT μπορεί να εμποδίζουν τη σύνδεση.

Ο localhost (`http://127.0.0.1`) θεωρείται αξιόπιστο περιβάλλον από τους browsers και υποστηρίζει τις απαιτούμενες web λειτουργίες. Για μεταφορά μέσω WebRTC **χρειάζεται internet για signaling** ακόμη κι αν και οι δύο συσκευές είναι στο ίδιο Wi-Fi. Αυτή η λύση δεν χρησιμοποιεί πραγματική IP του iPhone και δεν απαιτεί εγκατάσταση δεύτερης εφαρμογής στο iPhone.

**Εναλλακτικά:** Αν δεν θέλεις να τρέξεις το Windows launcher, μπορείς να ανοίξεις απευθείας τη σελίδα `/pc-transfer.html` του DriveTunes στον browser του PC και να βάλεις τον ίδιο κωδικό. Η τοπική IP υπάρχει για να πληκτρολογείς εύκολα μια σταθερή διεύθυνση στο PC.
