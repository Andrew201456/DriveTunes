# DriveTunes Offline Music

**Ένας απλός, ιδιωτικός music player για iPhone και Android.** Δεν υπάρχει backend, λογαριασμός, συγχρονισμός με cloud ή ανέβασμα τραγουδιών. Τα αρχεία μουσικής αποθηκεύονται ως Blob σε **IndexedDB** της συσκευής, και το interface λειτουργεί χωρίς internet μέσω Service Worker.

## Πώς το χρησιμοποιείς στο iPhone

1. Ανέβασε το project σε HTTPS hosting με τα αρχεία στην ίδια δομή (GitHub Pages, Cloudflare Pages κ.λπ.). Δεν αρκεί να ανοίξεις το HTML απευθείας από τα Αρχεία ή μέσω `file://`.
2. Άνοιξε το δημόσιο HTTPS URL στο **Safari**.
3. Πάτησε **Κοινοποίηση → Προσθήκη στην Αρχική οθόνη → Προσθήκη**. Επίλεξε «Άνοιγμα ως εφαρμογή» αν εμφανίζεται.
4. Άνοιξε **το εικονίδιο DriveTunes από την αρχική οθόνη** και **τότε** πάτα **«Προσθήκη τραγουδιών»**.
5. Διάλεξε MP3, M4A/AAC, WAV ή άλλο υποστηριζόμενο αρχείο από την εφαρμογή **Αρχεία**. Μπορείς να επιλέξεις πολλά.
6. Όταν τελειώσει η εισαγωγή, βάλε **Λειτουργία πτήσης** και δοκίμασε την αναπαραγωγή. Τα εισαγμένα τραγούδια βρίσκονται τοπικά.
7. Για το αυτοκίνητο, σύνδεσε το iPhone στο Bluetooth του αυτοκινήτου μέσω **Ρυθμίσεις → Bluetooth**. Το DriveTunes χρησιμοποιεί την κανονική έξοδο ήχου του iPhone· δεν κάνει ξεχωριστό pairing.

**Πολύ σημαντικό:** Στο iPhone η εφαρμογή που ανοίγει από την αρχική οθόνη και η καρτέλα Safari μπορεί να χρησιμοποιούν **ξεχωριστή αποθήκευση**. Γι' αυτό: *πρώτα εγκατάσταση, μετά εισαγωγή μουσικής μέσα από το εικονίδιο*.

## Λειτουργίες

- Εισαγωγή πολλών αρχείων με το native file picker (και drag & drop σε υπολογιστή).
- Πραγματική αποθήκευση ήχου ως Blob σε IndexedDB (χωρίς ανεβάσματα σε server).
- Αναπαραγωγή, παύση, seek, προηγούμενο, επόμενο, shuffle, repeat all/repeat one.
- Αγαπημένα, αναζήτηση, ταξινόμηση, μετονομασία τίτλου/καλλιτέχνη, διαγραφή από εφαρμογή.
- Αναγνώριση βασικών ID3 τίτλου/καλλιτέχνη/album από MP3, ή ανάγνωση `Artist - Title.mp3` από το όνομα αρχείου.
- Προφόρτωση **μόνο** του επόμενου τραγουδιού, για πιο άμεση μετάβαση (χωρίς διατήρηση ολόκληρης της συλλογής στη μνήμη).
- Media Session API για χειριστήρια οθόνης κλειδώματος / Bluetooth **όπου το επιτρέπει η έκδοση iOS και ο browser**.
- PWA icon, manifest, service worker για offline interface, αίτημα `navigator.storage.persist()` όπου υποστηρίζεται.

## Περιορισμοί iPhone / Safari — διάβασε πριν βασιστείς στο player

- Το iOS **δεν εγγυάται** μόνιμη αποθήκευση των IndexedDB αρχείων. Αν εκκαθαριστούν δεδομένα εφαρμογής/browser, αφαιρεθεί το web app ή δεν υπάρχει χώρος, ενδέχεται να χαθεί η offline βιβλιοθήκη. **Κράτησε πάντα τα πρωτότυπα αρχεία στην εφαρμογή Αρχεία / σε αντίγραφο ασφαλείας.**
- Η συνέχιση της αναπαραγωγής με **κλειδωμένη οθόνη**, το αυτόματο πέρασμα στο επόμενο τραγούδι και τα Bluetooth πλήκτρα μπορεί να μη λειτουργούν πάντα στο Safari/PWA. Υπάρχουν γνωστοί περιορισμοί του WebKit. Μην θεωρείς ένα web app ισοδύναμο με native iOS audio app.
- Τα υποστηριζόμενα codecs εξαρτώνται από το iOS/Safari. MP3 και M4A/AAC είναι συνήθως οι ασφαλέστερες επιλογές. Δεν υπάρχει μετατροπή αρχείων.
- Η offline μουσική **δεν συγχρονίζεται** μεταξύ συσκευών ούτε αποθηκεύεται στο GitHub. Τα νέα τραγούδια εισάγονται ξεχωριστά σε κάθε συσκευή / web app.
- Η πρώτη εγκατάσταση και η λήψη της εφαρμογής απαιτούν πρόσβαση σε internet. Μετά την πρώτη επιτυχημένη φόρτωση, η εφαρμογή μπορεί να ανοίξει offline.
- Ρύθμισε την αναπαραγωγή **πριν ξεκινήσεις να οδηγείς**, και χρησιμοποίησε τα χειριστήρια του αυτοκινήτου μόνο αν λειτουργούν αξιόπιστα.

## Δημοσίευση

**GitHub Pages:** Δημιούργησε ένα δημόσιο repository, ανέβασε τα παραπάνω αρχεία στη ρίζα και ενεργοποίησε **Settings → Pages → Deploy from a branch → main → /(root)**. Περίμενε να εμφανιστεί το `https://<username>.github.io/<repo>/` URL. Ο player χρησιμοποιεί relative paths ώστε να λειτουργεί και κάτω από repository path.

**Cloudflare Pages:** Δημιούργησε νέο Pages project από το repository. Για στατικά αρχεία χωρίς build, επίλεξε τη ρίζα του repository ως output directory (ή το deployment mode που επιτρέπει απευθείας στατικό upload). Μη δίνεις στα τραγούδια public URL: τα αρχεία θα αποθηκεύονται αποκλειστικά στον browser.

**Τοπικός έλεγχος:**

```bash
python3 -m http.server 8080
```

Άνοιξε `http://localhost:8080`. Οι Service Workers απαιτούν HTTPS ή localhost.

## Ασφάλεια / ιδιωτικότητα

- Δεν υπάρχει API για μουσική, streaming, tracking ή analytics.
- Τα audio Blob δεν μεταφορτώνονται: μόνο τοπική πρόσβαση μέσω browser storage.
- Τα αντικείμενα URL ανακαλούνται όταν αλλάζει ή διαγράφεται τραγούδι.
- Το Service Worker cache περιέχει **μόνο** τον κώδικα, τα εικονίδια και το UI — όχι τα προσωπικά μουσικά αρχεία.
